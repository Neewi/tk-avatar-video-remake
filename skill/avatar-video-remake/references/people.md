# 创建人物与另存造型

1. **输入。** 有文字就从文字提取人物外观、气质和服饰；收到人物参考图时，先看图，把宽泛的外观、造型和气质提炼成文字，重新设计虚构人物的脸型、五官组合和比例。此时调用图像生成仅发送文字，不传原人物图，也不引用最近的对话图片。没有描述时用一个简短问题引导：“想让什么样的人出镜？也可以直接发参考图。”不预设族裔、国籍或一律美式的场景。
2. **候选与命名。** 生成并实际展示一张面部清晰的半身候选图。未指定名字时默认建议一个与现有库区分的英文人物名，例如 Mason，并请用户确认或自行取名；用户指定的中文、英文或其他名字均直接沿用。这个规则针对数字人的显示名，不是目录名；已保存的人物不自动改名。造型名单独描述衣着风格，可继续使用中文。回复名字或说“就用这个”即可确认。要修改就按反馈重新出预览；认可后才补全四视图。把脸型、五官比例、肤色与体型写成人物固定描述，发型、衣服、鞋与配饰写入造型描述。
3. **换装或发型。** 用已保存的数字人脸部和全身图共同约束身份。根据文字或服装参考图提取版型、面料、配色、搭配；若参考中有真人，使用服饰细节或其文字描述，避免带入模特的脸。发型变更时保留脸型与五官。先展示一张能看清变化的候选图，请运营确认或指出想改的地方。认可后在同一人物下新增有辨识度的造型名，复刻任务改选该套。尚未建人就请求换装时，引导先建人再接回需求。
4. **四张独立高清参考图。** 使用可用的图像生成/编辑工具，以刚认可的候选图为身份参考，逐视角分别生成下表的独立图片，不从低分辨率宫格裁图作为最终人物素材。先查看本地参考图片再传给工具。请求工具支持的高原生分辨率，优先 2K 或更高；实际读取生成文件尺寸，单张最低短边 1024、长边 1536 像素。提示词不等于尺寸设置，工具没有尺寸参数或返回未达 2K 时如实告知实际尺寸，不把插值拉大称为高清。头像以脸部为主，全身用竖构图、人物占画面高度约 85%–95%，保留帽子、手和鞋，避免空背景消耗像素。逐张查看并以原尺寸检查脸部、胡须和衣料细节，确保同一张脸、身材、发型、服饰、鞋履与颜色；背景干净，无字、拼缝或外来道具。失败视角单独重做，保存为真正 PNG。升级现有图片时先把旧图备份到 workspace/runs/，沿用人物与造型 ID。没有图像生成能力时保留输入和制作进度，告知缺少哪一步。
   
   | 文件 | 画面 |
   |---|---|
   | portrait.png | 正面肩部以上近照，自然表情，五官清晰 |
   | three-quarter.png | 四分之三侧面半身，脸部轮廓及发型可辨 |
   | full-front.png | 正面全身，双手和鞋履可见 |
   | full-back.png | 侧后方全身，后脑、衣服背部及鞋履可见 |

5. **入库。** 四图放在 workspace/runs/ 下的本次独立草稿目录。运行下列命令之一（示例名和路径替换为实际值）；脚本只在四图都可读时发布，并返回 ID 与目录。新建人物和首套造型一次保存。换装复用 people 列表中的人物 ID，继承人物固定描述。重名时给出可区分的名字；中断续跑先查询 people 是否已保存，避免重复。展示实际保存的头像和全身图；按 sharing.md 同步本次新增文件夹，再返回待复刻任务继续。

   ```sh
   python3 scripts/studio.py --project <项目根目录> save-look --new-person '小夏' --look '海边休闲装' --identity '实际固定外观' --description '实际服饰及发型' --images '/实际草稿目录'
   python3 scripts/studio.py --project <项目根目录> save-look --person-id '人物ID' --look '健身装' --description '实际服饰及发型' --images '/实际草稿目录'
   ```
